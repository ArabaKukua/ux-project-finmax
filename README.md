# Finmax Teens — Financial Literacy App Prototype

**UX/UI Design Case Study | Araba Adenu-Mensah, UX/UI & Graphic Designer, Lethbridge, AB**

Finmax Teens is an app prototype created to improve financial literacy in teens, helping young users understand money in a clear, approachable way.

- **My role:** UX/UI Designer
- **Focus:** Teen financial literacy, clear information, and an intuitive app experience
